# what’s popular?

The repository now has two deployable surfaces:

- [`website/`](website/) — the existing
  Cloudflare-compatible Next/Vinext website and its content pipeline.
- [`mobile/`](mobile/) — the native SwiftUI iOS
  app with the condensed one-page briefing and persisted leaderboard layout
  customization.

Run website commands from `website/`. Open
[`mobile/WhatspopularMobile.xcodeproj`](mobile/WhatspopularMobile.xcodeproj)
in Xcode to run or archive the app. See the two folder READMEs for details.
